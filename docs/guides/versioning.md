# Versioning and roadmap

## Current status

AZ UI is in pre-release development (`0.x`). The package is not published to npm yet. Everything listed as available below is implemented, documented and covered by automated tests in the repository.

| Area                   | Status      | Contents                                                                                                                         |
| ---------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Foundations            | Available   | Tokens, light and dark themes, three font families, utilities with responsive variants                                           |
| Basic components       | Available   | Button, Badge, Alert, Spinner, Skeleton, Divider, Card, Avatar, Icon (253 icons)                                                 |
| Forms                  | Available   | Inputs, textarea, select and multi-select, checkbox, radio, switch, range, file upload, datepicker, counters, declarative API    |
| Interactive components | Available   | Modal, Offcanvas, Dropdown, Tooltip, Popover, Tabs, Accordion, Toast, Notification, Command menu, Context menu                   |
| Data components        | Available   | Table, DataTable, Pagination, Filter, Search, Toolbar, Timeline, Progress, Stat, Status indicator, Key value, List group         |
| Layouts                | Available   | Container, Grid, Row and Column, Stack, Split layout, Page header, Content section, Breadcrumb, Navigation menu, Navbar, Sidebar |
| Documentation          | In progress | This site: catalog, guides, example screens                                                                                      |
| Distribution           | Planned     | Production build review, final tests, first npm release                                                                          |
| PHP adapter (`AZForm`) | Planned     | Separate package to build forms from PHP                                                                                         |

## Under evaluation

These are directions for enterprise use. They are not implemented and have no date; they are listed so you can plan around them.

- Right-to-left layouts and internationalization of component labels.
- Dense and compact variants for more components.
- Date and time ranges.
- A long-term support policy for released major versions.
- Framework wrappers, if real usage shows the plain patterns in [Frameworks](frameworks.md) are not enough.

## Semantic Versioning

From `1.0.0`, AZ UI follows [Semantic Versioning](https://semver.org/):

- **Patch**: bug fixes that do not change documented behavior.
- **Minor**: new components, options and tokens that are backward compatible.
- **Major**: removals or changes to documented class names, tokens, options, events or markup structure.

Before `1.0.0`, minor versions may include breaking changes. Each one is listed in the changelog with a migration note.

## What is public API

Public and covered by compatibility: documented CSS classes, `--az-*` tokens, exported classes, options, methods and events, `data-az-*` attributes and the `AZUI` namespace.

Not public: internal markup generated by components (for example the inner structure of a custom select), undocumented classes and the order of CSS rules.

## Changelog

Every visible change is recorded in `CHANGELOG.md` under _Unreleased_ until it is released.
