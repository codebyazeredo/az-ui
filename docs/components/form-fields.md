# Form fields

CSS for inputs, textarea, select, multi-select, file, range, input group, checkbox, radio and switch, plus help and error messages. The same markup is generated by [`AZUI.Form`](../forms/declarative-api.md).

## Example

```html
<div class="az-field">
  <label class="az-field-label az-field-label-required" for="email">Email</label>
  <input
    class="az-control"
    id="email"
    name="email"
    type="email"
    required
    aria-invalid="true"
    aria-describedby="email-error"
  />
  <p class="az-field-error" id="email-error">Email already registered</p>
</div>

<div class="az-field">
  <div class="az-check">
    <input class="az-check-input" id="terms" name="terms" type="checkbox" />
    <label class="az-check-label" for="terms">Accept the terms</label>
  </div>
</div>

<div class="az-field">
  <div class="az-switch">
    <input class="az-switch-input" id="alerts" name="alerts" type="checkbox" role="switch" />
    <label class="az-switch-label" for="alerts">Email alerts</label>
  </div>
</div>
```

## Classes

| Class                                             | Purpose                                                                  |
| ------------------------------------------------- | ------------------------------------------------------------------------ |
| `az-field`                                        | Wrapper: label, control, help and error.                                 |
| `az-field-label`, `az-field-label-required`       | Label and required marker.                                               |
| `az-field-help`, `az-field-error`                 | Help and error messages.                                                 |
| `az-fieldset`, `az-fieldset-legend`               | Semantic group of fields.                                                |
| `az-control`                                      | Text-like controls (`input`, `textarea`, `select`).                      |
| `az-control-sm`, `az-control-lg`                  | Sizes (28px, 40px; default 32px).                                        |
| `az-textarea`, `az-select`                        | Added to `az-control` on `<textarea>` and `<select>`.                    |
| `az-control-invalid`, `az-control-valid`          | Validation state. `aria-invalid="true"` also marks invalid.              |
| `az-multiselect`                                  | Added to `az-control` on `<select multiple>`. See [Select](./select.md). |
| `az-file`                                         | Added to `az-control` on `<input type="file">`.                          |
| `az-range`                                        | `<input type="range">` (no `az-control`).                                |
| `az-input-group`, `az-input-group-text`           | Prefix or suffix text attached to a control.                             |
| `az-field-counter`                                | Character counter below a control.                                       |
| `az-check`, `az-check-input`, `az-check-label`    | Checkbox and radio.                                                      |
| `az-check-sm`, `az-check-lg`                      | Sizes, applied to `az-check`.                                            |
| `az-switch`, `az-switch-input`, `az-switch-label` | Switch (`role="switch"` on a checkbox).                                  |
| `az-switch-sm`, `az-switch-lg`                    | Sizes, applied to `az-switch`.                                           |

## Character counter

```html
<textarea
  class="az-control az-textarea"
  id="bio"
  maxlength="200"
  data-az-component="counter"
  data-az-target="#bio-counter"
  aria-describedby="bio-counter"
></textarea>
<p class="az-field-counter" id="bio-counter">0 / 200</p>
```

```ts
import { Counter } from "az-ui";

new Counter("#bio", { target: "#bio-counter" });
```

The field needs `maxlength`, otherwise `Counter` throws. The text is updated on every `input`; `destroy()` stops it.

## States

Default, hover, focus, disabled (dimmed, `not-allowed` cursor), readonly (muted background and dashed border), invalid and valid.

## Accessibility

- Every control needs a `<label for>` that matches its `id`.
- Link help and error text with `aria-describedby`; set `aria-invalid="true"` on invalid controls.
- Group radios and related checkboxes in a `<fieldset>` with a `<legend>`.
- The library only presents errors; validation belongs to the consumer.
