# Badge

Compact indicator of category or status. CSS only.

## Example

```html
<span class="az-badge az-badge-success">Active</span>
```

## Classes

| Class                                                                                          | Purpose                                   |
| ---------------------------------------------------------------------------------------------- | ----------------------------------------- |
| `az-badge`                                                                                     | Base (required). Neutral.                 |
| `az-badge-primary`, `az-badge-success`, `az-badge-warning`, `az-badge-danger`, `az-badge-info` | Variants.                                 |
| `az-badge-sm`, `az-badge-lg`                                                                   | Sizes (16px and 24px line; default 20px). |

## Accessibility

Color is never the only carrier of meaning: always include text such as "Active" or "Overdue".

## Notes

Use badges only for information that needs emphasis, such as status columns.
