# Glossário — Termos técnicos

| Termo | Definição |
|---|---|
| Core | Núcleo técnico da biblioteca. |
| DOM | Document Object Model. |
| DOM Factory | Função responsável por criar elementos DOM. |
| Event Delegation | Tratamento centralizado de eventos. |
| Lifecycle | Ciclo de vida de um componente. |
| Initialization | Inicialização de um componente. |
| Destroy | Finalização e limpeza de recursos. |
| Instance | Instância de um componente. |
| Renderer | Responsável pela geração de estrutura visual. |
| Controller | Responsável pelo controle de comportamento, quando essa separação for apropriada. |
| Export | Elemento disponibilizado publicamente pelo pacote. |
| Tree Shaking | Remoção de código não utilizado pelo bundler. |
| Side Effect | Comportamento executado como consequência da importação de um módulo. |
| ESM | Formato de módulos JavaScript moderno. |
| CJS | Formato CommonJS. |
| IIFE | Bundle autoexecutável para uso via `<script>` (versão global). |
| Type Declaration | Declaração de tipos TypeScript (`.d.ts`). |
| Adapter | Integração opcional com outra tecnologia. |
| SSR | Geração de HTML no servidor, sem DOM de navegador. |
| Baseline | Conjunto mínimo de navegadores e recursos suportados. |
