# Glossário — Design System

| Termo | Definição |
|---|---|
| Typography | Sistema de fontes, pesos, tamanhos e alturas de linha. |
| Font Family | Família tipográfica. |
| Font Weight | Peso da fonte. |
| Font Size | Tamanho da fonte. |
| Line Height | Altura da linha. |
| Letter Spacing | Espaçamento entre caracteres. |
| Color Palette | Conjunto de cores oficiais. |
| Color Scale | Sequência de tons de uma mesma cor (ex.: primary 50–900). |
| Semantic Token | Token com significado de uso (`--az-color-danger`), em oposição ao valor bruto. |
| Surface | Superfície visual de um elemento. |
| Border | Contorno de um elemento. |
| Radius | Arredondamento dos cantos. |
| Shadow | Sombra de um elemento. |
| Spacing | Sistema de espaçamentos. |
| Density | Quantidade de informação apresentada em determinado espaço (compacta ou confortável). |
| Contrast | Diferença visual entre elementos; medida pela razão de contraste WCAG. |
| Focus Ring | Indicador visual de foco. |
| Breakpoint | Largura de viewport em que o layout muda. |
| Motion | Transições e animações. |
