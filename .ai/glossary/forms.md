# Glossário — Formulários

| Termo | Definição |
|---|---|
| Form | Estrutura de formulário. |
| Field | Campo individual de formulário (label + controle + ajuda + erro). |
| Input | Campo de entrada de dados. |
| Textarea | Campo de texto multilinha. |
| Select | Campo de seleção. |
| Checkbox | Campo de seleção independente. |
| Radio | Campo de seleção exclusiva dentro de um grupo. |
| Switch | Controle visual de alternância. |
| Label | Identificação de um campo. |
| Placeholder | Texto auxiliar exibido quando o campo está vazio. |
| Help Text | Orientação complementar ao usuário. |
| Error Message | Mensagem de erro de validação. |
| Input Group | Agrupamento visual de campos ou elementos associados. |
| Prefix | Conteúdo exibido antes do valor do campo. |
| Suffix | Conteúdo exibido depois do valor do campo. |
| Validation State | Estado visual de validação do campo. |
| Required | Indicação de preenchimento obrigatório. |
| Disabled | Campo indisponível para interação. |
| Readonly | Campo disponível para leitura, sem edição. |
| Fieldset | Agrupamento semântico de campos. |
| Legend | Título de um fieldset. |
| API declarativa | `AZUI.Form.*`: construção de campos a partir de objetos de opções. |
