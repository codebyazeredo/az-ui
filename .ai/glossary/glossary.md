# Glossário oficial — AZ UI

Índice. Termos específicos em: `design-system.md`, `components.md`, `forms.md`, `technical-terms.md`. Convenções de nomenclatura em `../conventions/naming.md`.

## Conceitos fundamentais

| Termo | Definição |
|---|---|
| AZ UI | Biblioteca de interface e Design System do projeto. |
| Design System | Conjunto de regras, tokens, padrões e componentes visuais. |
| Foundation | Fundamentos visuais e técnicos da biblioteca. |
| Component | Elemento reutilizável com responsabilidade específica. |
| Utility | Classe CSS destinada a uma única finalidade. |
| Token | Variável oficial de design reutilizável. |
| Theme | Conjunto de configurações visuais aplicadas à interface. |
| Variant | Variação visual ou funcional de um componente. |
| State | Condição atual de um componente. |
| Primitive | Elemento básico utilizado na construção de componentes maiores. |
| API pública | Interface disponibilizada aos consumidores da biblioteca. |
| Adapter | Integração opcional com outra tecnologia (ex.: PHP). |
| Fase | Etapa do roadmap (`../development/roadmap.md`). |
| Consumidor | Projeto ou desenvolvedor que utiliza a AZ UI. |

## Termos proibidos como sinônimos oficiais

Não usar como substitutos arbitrários:

- Widget para qualquer componente.
- Template para qualquer layout.
- Helper para qualquer função.
- Plugin para qualquer módulo.
- Theme para qualquer conjunto de estilos isolados.
- Utility para componentes complexos.
- Framework para se referir à AZ UI sem necessidade.

Usar o termo técnico correto de acordo com a responsabilidade real do elemento.
