# Glossário — Componentes e estados

## Componentes

| Termo | Definição |
|---|---|
| Button | Elemento de ação. |
| Badge | Indicador compacto de categoria ou estado. |
| Alert | Mensagem contextual de informação, sucesso ou erro. |
| Card | Contêiner de conteúdo relacionado. |
| Modal | Janela sobreposta que exige atenção ou interação. |
| Dropdown | Menu de opções acionado por interação. |
| Popover | Conteúdo contextual sobreposto. |
| Tooltip | Informação auxiliar apresentada ao interagir com um elemento. |
| Tabs | Navegação entre painéis relacionados. |
| Accordion | Estrutura expansível e recolhível. |
| Toast | Notificação temporária. |
| Offcanvas | Painel lateral sobreposto. |
| Avatar | Representação visual de uma pessoa ou entidade. |
| Skeleton | Placeholder de conteúdo em carregamento. |
| Spinner | Indicador de carregamento. |
| Progress | Indicador de progresso. |
| Empty State | Representação de ausência de conteúdo. |
| Breadcrumb | Navegação hierárquica. |
| Timeline | Representação cronológica de eventos. |
| Toolbar | Conjunto de ações e controles relacionados. |
| Sidebar | Área lateral de navegação. |
| Navbar | Barra de navegação. |
| Page Header | Cabeçalho contextual de uma página. |
| DataTable | Tabela de dados com ordenação, paginação, seleção e ações. |

## Estados

| Termo | Definição |
|---|---|
| Default | Estado padrão. |
| Hover | Ponteiro sobre o elemento. |
| Focus | Elemento recebeu foco. |
| Active | Elemento está sendo ativado ou pressionado. |
| Disabled | Elemento desabilitado. |
| Loading | Elemento em processamento. |
| Selected | Elemento selecionado. |
| Checked | Controle marcado. |
| Expanded | Conteúdo expandido. |
| Collapsed | Conteúdo recolhido. |
| Invalid | Estado de validação inválida. |
| Valid | Estado de validação válida. |
| Readonly | Estado somente leitura. |
