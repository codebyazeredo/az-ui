Built for software people use all day

Dense by default
Controls are 32px tall and type starts at 15px, so a screen shows more data without feeling cramped. Small and large sizes exist for every control.
Accessible by design
Targets WCAG 2.2 AA: semantic HTML, visible focus, keyboard operation, focus management in overlays and reduced motion. See the accessibility guide for what is verified.
Themeable with tokens
Every color, size and radius is a CSS custom property. Rebrand a product, or one section of a page, by overriding tokens. See customization.
Independent of frameworks
Works in plain HTML, PHP templates, React, Vue, Angular and Svelte, with no runtime dependencies. See the framework guides.
