Select and multi-select

Dropdown list that replaces the native <select> and <select multiple> appearance. The native element stays in the DOM (hidden), so form submission, required, FormData, change events and labels keep working. Without JavaScript, the native control with the az-control az-select classes is shown instead.

Datepicker

Calendar attached to a text input. The value is always an ISO date (YYYY-MM-DD).

Example

File upload

Drop zone with a file list for <input type="file">. Files can be dropped, picked with the browser dialog (click, Enter or Space) and removed one by one. Image files get a thumbnail; others show an extension badge. Rejected files stay in the list with the reason.
